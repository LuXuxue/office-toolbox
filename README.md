# office-toolbox

| 脚本 | 作用 | 说明 |
|---|---|---|
| `docx2md.py` | `.docx` → `.md` | 抽取正文、表格、公式，还原 Word 的自动编号 |
| `md2docx.py` | `.md` → `.docx` | 生成 Word 文档，公式写成**可编辑的 Word 公式**而非图片或纯文本 |


## 安装

```bash
pip install -r requirements.txt
```

要求 Python 3.8 及以上（开发与验证环境为 3.13）。两个脚本都是单文件、无内部包依赖，可以单独拷走使用。

## 用法

### docx → md

```bash
python docx2md.py path/to/file.docx      # 转换单个文件
python docx2md.py -d path/to/dir         # 转换目录下所有 .docx
```

结果写在与 docx 同一目录、文件名相同的 `.md` 文件。目录模式下会打印 `完成: 成功 N / 共 N 个文件`，任一文件失败则退出码为 1。

### md → docx

```bash
python md2docx.py path/to/file.md        # 转换单个文件
python md2docx.py -d path/to/dir        # 把 path 当作目录，转换其中所有 .md
```

结果写在与 md 同一目录、文件名相同的 `.docx` 文件。

## docx2md 的转换规则

不是简单地「抽文本」，而是按 Word 的实际存储机制还原内容：

- **标题** — 按段落样式（`Heading N` / `标题 N`）映射到 `#`～`######`。Word 内置样式有 9 级而 Markdown 只支持 6 级，7 级以上统一压到 `######`。
- **自动编号** — Word 的序号不写在正文里，而是由 `numbering.xml` 定义、渲染时才显示。脚本重建了这套计算逻辑（含多级编号、中文数字、字母序号，以及 `表%1.%2-%3` 这类自定义编号模板），把序号补回文本。
- **表格** — 单元格里的竖线转义成 `\|`；支持合并单元格与多级表头（自动拍平成一行）；优先用 Word 自己记录的「重复标题行」判断表头，没有标记才按内容猜。
- **公式** — Word 公式是 OMML 标记而非文本。脚本把它还原成 LaTeX：块级公式输出 `$$…$$`，行内公式输出 `$…$`。
- **文档属性与域** — 封面、标题、`{ TITLE }` 这类内容常被包在内容控件（`w:sdt`）或简单域（`w:fldSimple`）里，直接遍历会整块丢失，脚本会穿透这些容器。
- **修订** — 插入的修订（`w:ins`）保留，已删除的（`w:del`）不出现。
- **分页符与分栏符** — 丢弃。它们只是排版指令，转成换行会把标题从中间截断。
- **中文排版** — 去除中文字符之间的多余空格；合并被换行拆开的序号与标题。

## md2docx 支持的 Markdown 语法

| 语法 | 处理方式 |
|---|---|
| `#`～`######` | 对应 Heading 1～6 样式 |
| `- ` / `* ` / `+ ` | 无序列表（按缩进层级嵌套） |
| `1. ` / `1) ` | 有序列表，每组新起一个编号实例，保证从 1 重新计数 |
| `\| 表格 \|` | 表格，统一使用 Table Grid 样式，表头加粗；`\|` 还原为竖线 |
| `> 引用` | 引用段落（合并连续的引用行为一段） |
| ` ``` ` 代码块 | 等宽段落 |
| `**粗体**` `*斜体*` `***粗斜体***` | 对应字符格式 |
| `` `代码` `` | 等宽字符 |
| `[文字](链接)` | 蓝色带下划线的文字（**不是**可点击的超链接） |
| `$$…$$` / `$…$` | 转成可编辑的 Word 公式（OMML） |
| `---` | 分隔线 |
| 其它 | 逐行写入普通段落 |

公式转换只覆盖 `docx2md` 会输出的那个 LaTeX 子集（分式、上下标、根号、上下限、求和积分、大括号矩阵、多行公式等）。遇到解析不了的内容会退回把 LaTeX 原文写成文本，不会丢内容。

## 已知限制

- **不提取图片**。docx 里的图片、图形、文本框内容都不会写入 md，回转后文档里没有这些对象。
- **不提取页眉页脚、脚注尾注、书签**。只处理正文（`w:body`）。
- **不保留域代码本身**，只保留域显示出来的结果文字。
- 复杂表格的合并单元格在 md 里被展开成按列对齐的矩形网格（`gridSpan` 补空格、`vMerge` 的续行重复首行文字）；`md2docx` 写回的是不带任何合并的矩形表格。
- `md2docx` 输出的文档页边距、页眉页脚等页面设置是 python-docx 默认值，不继承原 docx 的版式。
