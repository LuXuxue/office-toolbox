# office-toolbox

| 脚本 | 作用 | 说明 |
|---|---|---|
| `docx2md.py` | `.docx` → `.md` | 抽取正文、表格、公式，还原 Word 的自动编号 |
| `md2docx.py` | `.md` → `.docx` | 生成 Word 文档，公式写成**可编辑的 Word 公式**而非图片或纯文本 |
| `docx2pdf.py` | `.doc` / `.docx` → `.pdf` | 调用本机 Microsoft Word 批量导出 PDF（需要 Windows + Word） |


## 安装

```bash
pip install -r requirements.txt
```

要求 Python 3.8 及以上（开发与验证环境为 3.13）。三个脚本都是单文件、无内部包依赖，可以单独拷走使用。`docx2pdf.py` 额外需要本机安装 Microsoft Word；`pywin32` 已按平台条件写入 `requirements.txt`，非 Windows 平台安装时会自动跳过。

## 用法

### docx → md

```bash
python docx2md.py path/to/file.docx      # 转换单个文件
python docx2md.py -d path/to/dir         # 转换目录下所有 .docx
```

结果写在与 docx 同一目录、文件名相同的 `.md` 文件。目录模式下会打印 `完成: 成功 N / 共 N 个文件`，任一文件失败则退出码为 1。

### md → docx

```bash
python md2docx.py path/to/file.md        # 转换单个文件
python md2docx.py -d path/to/dir        # 把 path 当作目录，转换其中所有 .md
```

结果写在与 md 同一目录、文件名相同的 `.docx` 文件。

### docx → pdf

```bash
python docx2pdf.py                  # 转换当前工作目录
python docx2pdf.py path/to/dir      # 转换指定目录
python docx2pdf.py path/to/dir -r   # 递归处理子目录
python docx2pdf.py path/to/dir -f   # 覆盖已存在的 PDF
```

结果写在与源文件同目录、文件名相同的 `.pdf`。支持 `.doc` / `.docx` / `.docm` / `.dot` / `.dotx`，会自动跳过 Word 临时文件 `~$xxx`；默认不覆盖已有 PDF。需要本机安装 Microsoft Word。

导出先写到同目录下的临时文件 `.docx2pdf_tmp_*.pdf`，确认生成了非空的 PDF 后才替换目标文件。所以转换失败时原来那份 PDF 会原样保留，不会被删掉或留下 0 字节的坏文件。

## docx2md 的转换规则

不是简单地「抽文本」，而是按 Word 的实际存储机制还原内容：

- **标题** — 按段落样式映射到 `#`～`######`。优先看样式的大纲级别（`w:outlineLvl`，Word 导航窗格与目录就是按它认标题），所以中文模板自定义的「1级标题」「2级标题」这类样式名也能正确识别；样式名（`Heading N` / `标题 N` / `N级标题` / `一级标题`）作为兜底。段落或样式自己写明的大纲级别最权威，写成「正文」（`w:outlineLvl val="9"`）就不再当标题。Word 内置样式有 9 级而 Markdown 只支持 6 级，7 级以上统一压到 `######`。
- **自动编号** — Word 的序号不写在正文里，而是由 `numbering.xml` 定义、渲染时才显示。脚本重建了这套计算逻辑（含多级编号、中文数字、字母序号，以及 `表%1.%2-%3` 这类自定义编号模板），把序号补回文本。其中 `w:isLgl`（legal 编号）也按 Word 的实际显示还原：一级用中文「二.」时，二级仍显示「2.1.」而不是「二.1.」。
- **行内格式** — 加粗/斜体/删除线按 Word 的 run 边界还原，相邻且格式相同的 run 会合并，不会出现 `**前半****后半**` 这类碎标记。超链接整体写成一个 `[文字](地址)`，链接文字自己的加粗写在括号里面（`[**文字**](地址)`），这样回转成 Word 时地址不会被当成正文。
- **超链接** — Word 里超链接有好几种写法，都会被还原成 `[文字](地址)`：正文与表格单元格里的 `w:hyperlink` 元素、文档内部的书签链接（转成 `[文字](#书签)`）、写成域的链接（`HYPERLINK "地址"` 简单域与复杂域）、内容控件与修订里的链接、文本框里的链接。链接文字的加粗/斜体保留在括号里面。
- **表格** — 单元格里的竖线转义成 `\|`；支持合并单元格与多级表头（自动拍平成一行）；优先用 Word 自己记录的「重复标题行」判断表头，没有标记才按内容猜。
- **公式** — Word 公式是 OMML 标记而非文本。脚本把它还原成 LaTeX：块级公式输出 `$$…$$`，行内公式输出 `$…$`。表格单元格里的块级公式也只输出一次。
- **文档属性与域** — 封面、标题、`{ TITLE }` 这类内容常被包在内容控件（`w:sdt`）或简单域（`w:fldSimple`）里，直接遍历会整块丢失，脚本会穿透这些容器。
- **修订** — 插入的修订（`w:ins`）保留，已删除的（`w:del`）不出现。
- **分页符与分栏符** — 丢弃。它们只是排版指令，转成换行会把标题从中间截断。
- **中文排版** — 去除中文字符之间的多余空格；合并被换行拆开的序号与标题。

## md2docx 支持的 Markdown 语法

| 语法 | 处理方式 |
|---|---|
| `#`～`######` | 对应 Heading 1～6 样式 |
| `- ` / `* ` / `+ ` | 无序列表（按缩进层级嵌套） |
| `1. ` / `1) ` | 有序列表，每组新起一个编号实例，保证从 1 重新计数 |
| `\| 表格 \|` | 表格，统一使用 Table Grid 样式，表头加粗；`\|` 还原为竖线；分隔行可以不带竖线（`--- ---`）；数据行的单元格比表头多时全部保留，表头补空到同样的列数（并往 stderr 打一行警告） |
| `> 引用` | 引用段落（合并连续的引用行为一段） |
| ` ``` ` 代码块 | 等宽段落 |
| `**粗体**` `*斜体*` `***粗斜体***` `~~删除线~~` | 对应字符格式 |
| `` `代码` `` | 等宽字符 |
| `[文字](链接)` | 真正的可点击超链接（`w:hyperlink` + 指向地址的关系）；链接文字里的粗体/斜体/行内代码照常生效，地址里允许成对括号；`[文字](#书签)` 写成文档内部的书签链接 |
| `$$…$$` / `$…$` | 转成可编辑的 Word 公式（OMML） |
| `---` | 分隔线 |
| 其它 | 逐行写入普通段落 |

公式转换只覆盖 `docx2md` 会输出的那个 LaTeX 子集（分式、上下标、根号、上下限、求和积分、大括号矩阵、多行公式等）。遇到解析不了的内容会退回把 LaTeX 原文写成文本，不会丢内容。

## 已知限制

- **不提取图片**。docx 里的图片、图形本身都不会写入 md（文本框里的文字会当作普通文字写进去），回转后文档里没有这些对象。
- **不提取页眉页脚、脚注尾注、书签**。只处理正文（`w:body`）。
- **不保留域代码本身**，只保留域显示出来的结果文字。
- 复杂表格的合并单元格在 md 里被展开成按列对齐的矩形网格（`gridSpan` 补空格、`vMerge` 的续行重复首行文字）；`md2docx` 写回的是不带任何合并的矩形表格。
- `md2docx` 输出的文档页边距、页眉页脚等页面设置是 python-docx 默认值，不继承原 docx 的版式。
- 嵌套表格会被拍平：内层表格的文字并入外层单元格，不会生成嵌套的 Markdown 表格。
- `md2docx` 不处理图片语法：`![说明](图片地址)` 里的 `!` 会原样写成正文，地址部分则当作普通超链接。
